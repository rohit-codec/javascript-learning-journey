# Banking Calculator

A simulated account to practice JavaScript operators and conditions. It is not connected to a real bank.

## Features
- Deposit and withdraw
- Prevent invalid amounts and overdrafts
- Transaction history
- Simple interest estimate
- Reset demo balance

## Run
Open `index.html` in a browser or use Live Server.

## Concepts
Variables, arithmetic and assignment operators, comparisons, conditions, functions, events, arrays, validation, template literals, and `Intl.NumberFormat`.

Formula: simple interest = principal × annual rate × months / 12.
