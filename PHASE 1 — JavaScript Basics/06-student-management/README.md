# Student Management System

## Features
- Add students with name, roll number, and marks
- Validate marks and prevent duplicate roll numbers
- Search and sort records
- Calculate grade and delete students

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Concepts practiced
Arrays, objects, functions, `filter()`, `sort()`, `some()`, `findIndex()`, `splice()`, DOM manipulation, events, event delegation, and validation.

## Extensions
Add edit records, class average/topper, and LocalStorage persistence.
