# Product Inventory System

## Features
- Add products with category, price, and stock
- Search products by name/category
- Increase/decrease stock and delete products
- Calculate total products, units, and inventory value

## Run
Open `index.html` in a browser or use Live Server.

## Concepts practiced
Objects, arrays, `filter()`, `findIndex()`, `reduce()`, `splice()`, event delegation, DOM manipulation, validation, and `Intl.NumberFormat`.

## Extensions
Add edit product, low-stock warnings, sorting, and LocalStorage.
