# ATM Simulator

A menu-driven ATM simulation built with HTML, CSS, and JavaScript. No bank connection or real money is involved.

## Features
- Check balance, deposit, and withdraw
- Validate amounts and prevent overdrafts
- Change a demo PIN
- Exit the simulated session

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Concepts
Conditions, event delegation, functions, DOM element creation, form events, validation, regular expressions, and currency formatting.

Demo starting balance: ₹5,000. Starting PIN: `1234`.
