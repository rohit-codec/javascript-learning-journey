# Text Analyzer

Analyze text length and transform text in the browser.

## Features
- Count characters, non-whitespace characters, words, and approximate sentences
- Estimate reading time and find the longest and most frequent words
- Uppercase, lowercase, reverse, copy, clear, and load sample text

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Concepts
Strings, regular expressions, arrays, `reduce()`, `Map`, template literals, DOM manipulation, event handling, and Clipboard API.

## Notes
Sentence counting is approximate. Reading time is estimated at 200 words per minute. Clipboard access may require HTTPS or localhost.
