# Everyday Calculator

A responsive calculator for basic arithmetic.

## Features
- Addition, subtraction, multiplication, division, and remainder
- Decimal input, clear, backspace, and keyboard support
- Basic invalid-expression and non-finite result handling

## Run
Open `index.html` in a browser or use Live Server.

## Concepts
Functions, event delegation, strings, regular expressions, conditionals, keyboard events, and DOM updates.

## Note
This is a learning demo. Production calculators should use a dedicated expression parser rather than JavaScript's `Function` constructor.
