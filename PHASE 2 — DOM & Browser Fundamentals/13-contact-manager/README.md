# Smart Contact Manager

## Purpose
Practice project for Phase 2 JavaScript.

## Run
Open `index.html` in a browser or use VS Code Live Server. No package installation is needed.

## Concepts practiced
JSON, regex, arrays, search/filter, DOM, form validation, Blob download.

## Files
- `index.html` — structure
- `style.css` — styling
- `script.js` — logic

## Extensions
Improve the UI, add edge-case validation, and add persistence or accessibility features where applicable.
