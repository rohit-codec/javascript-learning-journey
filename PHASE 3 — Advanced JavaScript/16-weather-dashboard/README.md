# Weather Dashboard

Fetch current weather from Open-Meteo using city search.

## Run
Open `index.html` in a browser or use VS Code Live Server. Some browser APIs require localhost, HTTPS, or permission.

## Concepts practiced
Fetch API, async/await, promises, JSON, HTTP errors, URL encoding.

## Files
- `index.html` — page structure
- `style.css` — styling
- `script.js` — behavior
