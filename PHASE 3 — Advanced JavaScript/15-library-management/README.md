# Library Management System

Use classes to manage books and issue/return states.

## Run
Open `index.html` in a browser or use VS Code Live Server. Some browser APIs require localhost, HTTPS, or permission.

## Concepts practiced
Classes, constructors, instance methods, objects, arrays, events.

## Files
- `index.html` — page structure
- `style.css` — styling
- `script.js` — behavior
