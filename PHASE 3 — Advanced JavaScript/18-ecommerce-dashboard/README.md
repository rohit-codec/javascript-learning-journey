# E-commerce Product Dashboard

Browse products, search, and add items to a cart.

## Run
Open `index.html` in a browser or use VS Code Live Server. Some browser APIs require localhost, HTTPS, or permission.

## Concepts practiced
Destructuring concepts, Map, arrays, filtering, reduce, DOM updates.

## Files
- `index.html` — page structure
- `style.css` — styling
- `script.js` — behavior
