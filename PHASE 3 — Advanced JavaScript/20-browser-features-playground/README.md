# Browser Features Playground

Try Clipboard, URL parameters, geolocation, and IntersectionObserver.

## Run
Open `index.html` in a browser or use VS Code Live Server. Some browser APIs require localhost, HTTPS, or permission.

## Concepts practiced
Clipboard API, URL, URLSearchParams, Geolocation, IntersectionObserver.

## Files
- `index.html` — page structure
- `style.css` — styling
- `script.js` — behavior
