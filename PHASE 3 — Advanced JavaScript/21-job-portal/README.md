# Job Portal Frontend

Search, filter, and paginate through sample job listings.

## Run
Open `index.html` in a browser or use VS Code Live Server. Some browser APIs require localhost, HTTPS, or permission.

## Concepts practiced
Search/filter, arrays, pagination, DOM rendering, event handlers.

## Files
- `index.html` — page structure
- `style.css` — styling
- `script.js` — behavior
